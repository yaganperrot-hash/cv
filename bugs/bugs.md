# Bugs ouverts

> Convention : un bug = un bloc. Id `BUG-000`, incrémental, jamais réutilisé.
> Statuts : `ouvert` | `en cours` | `en attente d'info` | `résolu`.
> Un bug résolu part dans `bugs/archive/YYYY-MM-DD-BUG-000-titre.md` avec sa résolution.
> Dernière mise à jour : 2026-08-26.

## Modèle

```
### BUG-000 — Titre court
- **Statut** : ouvert
- **Sévérité** : bloquant | majeur | mineur
- **Détecté le** : YYYY-MM-DD
- **Contexte** : où (script, CI, template…)
- **Repro** :
  1. …
  2. …
- **Attendu** : …
- **Obtenu** : …
- **Piste** : …
```
